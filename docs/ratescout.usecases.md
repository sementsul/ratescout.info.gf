**Слепая зона (честно):** watchdog — сам scheduled-workflow, при истечении PAT он отключится вместе с остальными

а данные не обновляются.
**Проверка (на реальном раннере):** `bash -n` OK; локально свежо→exit0, порог0→exit1 с `::error::`;
`workflow_dispatch` с `stale_hours=0` → прогон **failure** (ветка тревоги, письмо ушло бы);
обычный прогон (порог 8, данные свежие) → **success** (тревог нет).
**РАДИУС:** новый `.github/workflows/watchdog.yml`. Не трогает deploy/keepalive/сайт. Прав нужно только
`contents:read` (raw публичный), секретов не требует.
**Статус:** ✅ в проде (обе ветки проверены live).
